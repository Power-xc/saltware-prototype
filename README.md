# 솔트웨어 홈페이지 개편 프로토타입

명세 v0.2 기준 구조 프로토타입. **와이어프레임 밀도**이며 최종 디자인이 아니다.
본문 카피와 이미지는 회색 블록으로 두었고, 구조·흐름·계측만 확인한다.

## 무엇을 볼 수 있나

|           |                                                |
| --------- | ---------------------------------------------- |
| 라우팅    | 15개 경로 · 없는 주소는 404                    |
| 헤더      | 6그룹 GNB · 메가메뉴 3종 · 모바일 서랍         |
| 사업 상세 | 9블록 표준 틀이 6개 사업에 각각 적용           |
| 문의      | 4필드 검증 · 전화번호 자동 하이픈 · 2단계 전환 |
| 목록      | 정상 / 로딩 / 0건 / 오류 4개 상태              |

## 상단 도구

- **이벤트 로그** — 클릭할 때마다 발화하는 `dataLayer` 이벤트를 실시간으로 표시한다. 계측 taxonomy 검증용.
- **목록 상태 전환** — 목록 화면의 4개 상태를 순환한다.
- **내부 메모** — 기획 단계의 제약·잠금 항목을 표시한다. 기본은 꺼짐.

## 확정되지 않은 것

- 라우팅 정본과 기존 URL 리다이렉트 맵
- 문의 유형 taxonomy (analytics·CRM 고정 전)
- 사업부별 2차 CTA 일부

## 배포

GitHub Pages · `main` 브랜치 루트. 검색 색인은 `robots.txt`와 `noindex` 메타로 막아 두었다.
