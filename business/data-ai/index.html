CAPABILITIES

어디까지
맡길 수 있나

솔트웨어가 공개한 AI 서비스 제공 범위입니다. 컨설팅에서 운영 지원까지 고객 맞춤형으로 제공합니다.

범위 1

도입 컨설팅

  • 생성형 AI 도입 여부 검증, 교육, 모델 선택까지 단계별로 함께 판단합니다.

범위 2

기반 인프라 구축

  • 쿠버네티스 기반 데이터 엔지니어링 역량을 바탕으로 AI가 돌아갈 환경을 구성합니다.

범위 3

모델·데이터 세팅

  • 프롬프트 작성과 필요한 정보 삽입, 파운데이션 모델 고도화를 수행합니다.

범위 4

시스템 구축과 운영 지원

  • 업무 시스템에 연결하고 운영을 이어서 지원합니다.

Amazon Bedrock 기반 생성형 AI 도입은 FitCloud AI 서비스로 단계별 컨설팅을 제공합니다.

PRODUCTS

Sapie 제품군

솔트웨어가 자체 개발해 공개하고 있는 AI 제품입니다.

Sapie-Bot

LLM 기반 챗봇. 24시간 Q&A 채널과 초개인화 업무 어시스턴트를 구성합니다.

Sapie-LLM

오픈소스 LLM 기반 자체 모델 시리즈. 4B~105B까지 목적에 맞춰 선택하고 도메인 특화 파인튜닝을 지원합니다.

Sapie-Guardian

챗봇 입력의 민감정보·개인정보를 자동 감지·마스킹하는 보안 필터링 솔루션.

Sapie-DeepQ

SQL 없이 한국어 자연어로 구조화된 데이터에 질의하는 솔루션.

Sapie-Chart

LLM·RAG로 차트를 분석해 유의미한 정보를 자연어로 제공합니다. BI 도구·리포트 자동화와 연계합니다.

Sapie-AgenticAI

MCP 기반 모듈화된 프롬프트 체계로 워크 에이전트를 구축하는 Agentic AI 플랫폼.

Sapie-Reco

사용자 의도와 행동 맥락을 분석하는 통합 추천 서비스.

Sapie-Braille

전자문서에 장애인 접근성을 자동 부여하고 점역 솔루션과 결합해 점자 도서를 제작합니다.

제품 소개서는 홈페이지에서 PDF로 공개하고 있습니다. 데이터 저장·분석 기반이 함께 필요한 경우 Databricks 사업과 연계해 진행합니다.

제품 소개서 요청하기
Sapie-Guardian이 입력 데이터에서 민감정보와 개인정보를 자동 감지해 마스킹합니다. 챗봇 사용 과정에서 기밀이 나가는 경로를 차단하는 것이 이 제품의 목적입니다.
아닙니다. Amazon Bedrock의 파운데이션 모델을 쓰는 구성과, 오픈소스 기반 자체 모델 Sapie-LLM(4B~105B)을 쓰는 구성 모두 가능합니다.
솔트웨어는 한국의 Anthropic AWS 공식 리셀러입니다. Claude API·Claude Enterprise 도입과 Bedrock 기반 구축을 함께 지원합니다.
Sapie-DeepQ는 한국어 자연어 입력만으로 구조화된 데이터에 질의하고 정보를 추출합니다. 차트 해석은 Sapie-Chart가 자연어로 설명합니다.
Sapie-AgenticAI는 MCP 기반 모듈화된 프롬프트 체계로 업무별 에이전트를 구성합니다. NIPA 과제에서는 4대 워크플로에 21종 에이전트를 배치합니다.
